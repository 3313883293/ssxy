v0.51 更新内容：灼华火焰特效优化——三技能专属火焰演出 + 火焰专属音效

按用户要求（「优化灼华特效：与火焰强相关」），为灼华的燃烧 dot 手三技能各定制专属火焰动画，对齐鲁盼旋专属演出（亮剑/剑气/开创）的等级，延续「慢而炫、夸张化」风格。改动纯表现层，机制零改动。

## 灼华三技能火焰动画（SkillSystem.js）

| 技能 | 原特效 | 新特效 | 新动画 type |
|---|---|---|---|
| 燃木（施加 2 层燃烧） | 普通直线打击线 | **火球飞击**：灼华卡前凝火苗 → 多层火苗层叠的圆形火球沿直线飞向目标（运动学初速慢→急速命中，复用剑气模式）→ 命中炸开火焰（橙红冲击波 + 🔥粒子四溅），伤害反馈在命中时刻同步 | `flameThrow`（_flameThrow） |
| 煽风（燃烧+2级/点燃） | 雾气扩散 | **火柱腾升**：8~12 个泪滴形火焰粒子从目标卡底向上逐批蹿升（火焰越烧越旺呼应升火）、顶部火星飘散，伤害反馈在火柱腾升中段（~300ms）同步 | `emberRise`（_emberRise） |
| 引爆（引爆真伤） | 打击线+枪口闪光 | **三层爆炸**（最华丽）：白闪→橙红→暗红外圈错开 80ms 依次扩散 + 🔥💥粒子高速飞射 + 目标卡震屏，伤害反馈起爆瞬间（~120ms）同步 | `fireBomb`（_fireBomb） |

三技能均走 `delayedHit` 演出型机制（伤害数字/受击音/死亡爆发延迟到命中时刻播放，与鲁盼旋演出技能同机制）；`playSkillTargetAnimation` 已加对应 return 防重复出招；坐标统一经 _animPoint/_getCardCenter/_animSize，位移乘 _dispScale（窄屏/横屏适配）。

## 火焰专属音效（audio.js）

- **flame**（燃木）：低频带通噪声上扫（火球呼啸飞出）+ 发射「噗」短噪声
- **ember**（煽风）：6 次随机小噪声脆响（火焰噼啪）+ 柔和带通噪声上扫（风声/火势）
- **bomb**（引爆）：锯齿波低频下坠（爆炸轰隆）+ 低通噪声爆轰 + 延迟二次回响

SKILL_SFX_MAP 加 flameThrow:flame / emberRise:ember / fireBomb:bomb。

- `.flame-ball`：火球（radial-gradient 橙黄亮心→橙红外焰 + 三重 box-shadow 火苗余晖），命中后 .fade 淡出

## 引爆计入结算统计（并入 v0.51，同日追加）

按用户反馈（「灼华的燃烧引爆怎么没有在结算页面显示为 dot 伤害」），修复引爆（detonate）伤害在结算页统计缺漏。纯统计层修复，战斗机制/数值零改动。

### 问题

结算页有两处伤害统计：

- **主伤害表**：`damageDealt`（各角色造成伤害）、`damageReceived`（受到伤害）
- **🔥 Dot伤害明细**：`dotDamageMap['burn']`（各角色受到的燃烧 dot 伤害）

回合末「燃烧」结算（battleFlow.js onTurnEnd）会写入 `dotDamageMap['burn']`；但引爆走 `takeTrueDamage` 直接结算真伤，该函数只记 `damageReceived`，**既不进目标 Dot 明细，也没给攻击者灼华加 `damageDealt`** → 引爆伤害在结算页两处都缺（仅日志有「💥 燃烧被引爆」文字）。

### 修复（SkillSystem.js 引爆块）

引爆结算后补两笔统计：

```js
target.dotDamageMap['burn'] = (target.dotDamageMap['burn'] || 0) + actual;  // 计入目标 Dot 明细
if (actor && actor.alive) actor.damageDealt += actual;                       // 计入攻击者「造成伤害」
```

引爆本质是「燃烧」的提前一次性结算（同为燃烧等级×50 真伤），归入 Dot 明细语义一致；引爆后 `clearBuff('burn')` 清空燃烧，后续回合不再结算，**不会与回合末 dot 双算**。

### 验证

新增 check-v051-dotstat.js（10 项，桌面 1280 走查灼华篇第一关）：引爆真伤精确计入 Dot 明细（300 = Lv3×50×2）；攻击者 `damageDealt` 增量 === 目标 `damageReceived` 增量（普通伤害抵消后精确证明引爆计入）；燃烧清零不双算；`onTurnEnd` 回合末燃烧结算回归正常（Lv2 经风助火势 +1 → Lv3 → 150 精确）。回归 verify-v050-zh（32）/ check-v05-flameanim（16）/ verify-v320（28）/ verify-v316（21）/ check-v05-responsive（15）全过（机制零改动）。
