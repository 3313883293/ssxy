v0.662 更新内容：修复手机端教程关弹窗遮挡（竖屏「确认出战」被拦 / 步骤③贴底残留 / 战斗页弹窗遮卡）

## 背景

用户反馈手机端教程关存在遮挡问题。用 Playwright 实测 3 种手机视口（竖屏 390×844 / 横屏短高 844×390 / 小横屏 667×375）走完教程关 12 步，逐帧测量弹窗与战斗头部/角色卡/底部面板/高亮目标的重叠比例，发现 3 类遮挡：

1. **竖屏选角页步骤②「确认出战」被贴底弹窗拦截**（硬阻断）：实测按钮被遮 77%，弹窗框体（pointer-events:auto）拦截点击，玩家点不到——根因是点角色卡后详情面板展开，把按钮推到视口底部，恰好落入贴底弹窗（v0.61 为避开顶部出战槽位而贴底）下方。
2. **竖屏战斗页步骤③弹窗错误贴底**：`advance('confirm')` 时选角页仍 active，`.tutorial-select` 类残留，`showPage('pageBattle')` 后不再重算——弹窗本应贴顶却贴底显示。
3. **战斗页弹窗遮角色卡**：竖屏步骤⑧（情感激荡图文步，弹窗 276px）把两张卡各遮 50%（该步正文正让玩家"看木偶卡片"）；667×375 小横屏图文步遮木偶卡 16~50%、遮战斗头部 6~17%；844×390 标准横屏无遮挡。

## 设计（用户指定）

- 教程弹窗在手机端永不做硬阻断：教学高亮目标、必需点击的按钮必须可点；
- 战斗页弹窗永不遮角色卡（卡片是教学观察对象），正文不足空间时内部滚动；
- 弹窗位置随页面切换/窗口变化即时重算（消除时序残留类）；
- 桌面端（≥901px）行为与 v0.661 完全一致。

## 改动（v0.661 → v0.662）

1. **js/tutorial.js**：
   - 新增 `syncPosition()`：统一管理弹窗贴边位置与战斗页限高——①竖屏选角页仅步骤①（char-select）贴底，步骤②起贴顶（避开被详情面板推到底部的「确认出战」）；②战斗页（≤900 触屏布局）检测与弹窗水平相交的角色卡，弹窗动态限高至最靠上卡片的顶边（下限 80px、上限视口 50%），正文 flex 压缩内部滚动，保证永不遮卡；与弹窗不相交（如 844 横屏卡居左弹窗居右）则不限高，正文完整展示；③弹窗 data-step 记录当前步骤供 CSS 区分。
   - `show()` 原静态 toggle 改为调用 `syncPosition()`；`toggleCollapse()` 展开时重算限高；`end()` 清理 maxHeight 残留。
   - 新增 `resize` / `orientationchange` 监听——横竖屏切换后贴边断点变化即时重算。
2. **js/ui.js**：`showPage()` 末尾调用 `Tutorial.syncPosition()`（弹窗未显示时自动跳过）——修复「确认出战」→ 战斗页后步骤③弹窗带 `.tutorial-select` 残留贴底的时序问题。
3. **style.css**：
   - 新增战斗页 flex 限高：`#tutorialOverlay.tutorial-battle .buff-popup` 改 flex 纵向布局；限高激活（JS 加 `.tutorial-clipped`）时正文 `flex:1 min-height:0 overflow-y:auto max-height:none`，头部/按钮固定、正文滚动；未激活保持各断点正文上限（弹窗不高耸遮底部操作面板）。
   - 竖屏 portrait 断点：`#tutorialOverlay.tutorial-select:not([data-step="char-select"])` 贴顶（步骤①仍贴底避槽位）。
   - 短高横屏断点：弹窗宽度 `min(280px,40vw)` → `min(240px,36vw)`，正文上限 28vh → 24vh（667×375 下不再压住居中的出战槽位/木偶卡边缘）。

## 自动适配（零改动）

- 桌面端不命中任何新增 CSS（tutorial-battle/tutorial-clipped 仅 ≤900 战斗页由 JS 动态加；portrait/短高断点不命中），`syncPosition` 在 >900 宽战斗页跳过限高——桌面行为与 v0.661 完全一致（check-v061 桌面 C1~C4 回归佐证）。
- 教程推进钩子、高亮机制、收起按钮（▾/▸）逻辑零改动。
